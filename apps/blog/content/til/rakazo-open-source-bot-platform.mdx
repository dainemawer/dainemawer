[Rakazo](https://rakazo.com/) is an open-source (Apache-2.0) platform for running AI bots on recurring work like email, sales outreach, expenses and code changes. It runs in the browser, on desktop and mobile, or on your own machine.

What caught my eye:

- **It doesn't resell models.** Sign in with a Claude Pro/Max or ChatGPT Plus/Pro subscription, or bring an API key, OpenRouter, or a local server like Ollama or LM Studio. You can pick a different model per bot.
- **Bots start from templates.** Inbox Manager, Sales Outbound, Expense Manager, Coding Agent, Chief of Staff and a few more.
- **Triggers beyond chat.** Bots can run on a schedule, a webhook, or an event such as a new GitHub issue. They connect to Gmail, GitHub, Notion and any MCP server.
- **Approvals are per action.** You choose which actions a bot has to ask about first.

The hosted plan includes up to 100 computer-hours a month and five computers at once. Self-hosting is free, and it's also the only way to message bots from iMessage/SMS, WhatsApp or Telegram. Slack works on both.

I'm setting it up today, so this is a first look from the site rather than a verdict.
